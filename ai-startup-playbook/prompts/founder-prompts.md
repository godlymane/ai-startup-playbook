# 🧠 50+ AI Prompts for Founders — The Complete Collection

## Category 1: Product Ideation & Validation (10 Prompts)

### 1. The "Billion Dollar Problem" Finder
```
You are a serial entrepreneur with 5 successful exits. Analyze the [INDUSTRY] market and identify:
1. The top 5 pain points that businesses spend >$10K/year trying to solve
2. Which of these could be solved with AI/automation
3. A SaaS product concept for each with pricing model
4. TAM/SAM/SOM estimates
5. Competitive landscape and unfair advantages

Be specific. No generic ideas. I want things I can build this weekend.
```

### 2. The "Competitor Teardown" Prompt
```
Analyze [COMPETITOR URL]. Give me:
1. Their exact pricing tiers and what's included
2. Their top 5 features users love (check G2/Capterra reviews)
3. Their top 5 complaints/weaknesses
4. Exactly how I can build something 10x better in 2 weeks
5. Their estimated revenue (use employee count, pricing, traffic estimates)
6. The positioning angle that beats them
```

### 3. The "Weekend MVP" Prompt
```
I want to build a SaaS MVP this weekend. I know [TECH STACK]. 
My target user is [PERSONA]. Their biggest pain is [PAIN POINT].

Give me:
1. The exact 3 features for the MVP (no more)
2. Database schema
3. API endpoints needed
4. UI wireframe description (3 screens max)
5. The landing page headline and subheadline
6. Pricing: what to charge on day 1
7. A step-by-step 48-hour build plan
```

### 4. The "Pricing Optimizer"
```
My SaaS does [DESCRIPTION]. Current pricing: [CURRENT PRICING].
Competitors charge: [COMPETITOR PRICING].
My users are: [USER PROFILE].

Optimize my pricing:
1. Price anchoring strategy
2. Feature gating (what goes free vs paid)
3. Annual vs monthly discount
4. Enterprise tier design
5. The psychological pricing tricks that increase ARPU 30%+
```

### 5. The "Market Sizing in 60 Seconds"
```
Calculate the market size for [PRODUCT IDEA]:
1. TAM: Total market if everyone who could use this, did
2. SAM: Realistic serviceable market
3. SOM: What I can capture in year 1
4. Show your math with data sources
5. Compare to 3 funded startups in adjacent spaces
6. Is this a VC-scale opportunity or a bootstrapped lifestyle business?
```

### 6. The "User Interview Script Generator"
```
I'm building [PRODUCT] for [PERSONA]. Generate:
1. A 15-minute user interview script
2. 10 open-ended questions that reveal real pain
3. 5 "gotcha" questions that expose if they'll actually pay
4. Follow-up questions for each response type
5. How to analyze responses and identify patterns
```

### 7. The "Landing Page Copy" Generator
```
Write high-converting landing page copy for [PRODUCT]:
- Hero: Headline + subheadline + CTA
- Problem section (3 pain points with emotional hooks)
- Solution section (3 benefits, not features)
- Social proof section (testimonial templates)
- Pricing section (3 tiers)
- FAQ (8 questions, overcome objections)
- Final CTA with urgency

Use the PAS framework. Write like a conversion copywriter with 10 years experience.
```

### 8. The "Cold Email Sequence"
```
Write a 5-email cold outreach sequence for selling [PRODUCT] to [PERSONA]:
- Email 1: Pattern interrupt + relevant insight
- Email 2: Case study / social proof
- Email 3: Direct value proposition
- Email 4: Breakup email with scarcity
- Email 5: Final follow-up

Subject lines should get >40% open rate. Body should be <100 words each.
```

### 9. The "Feature Prioritization" Framework
```
I have these feature requests for my SaaS: [LIST FEATURES]
My current MRR is [MRR]. I have [TEAM SIZE] developers.

Prioritize using:
1. ICE scoring (Impact, Confidence, Ease) for each feature
2. Revenue impact estimate per feature
3. Build time estimate
4. The exact order to build them
5. Which features to NEVER build (and why)
```

### 10. The "Pivot Detector"
```
My startup: [DESCRIPTION]
Metrics: [MRR, CHURN, GROWTH RATE, CAC, LTV]
We've been at this for [TIME PERIOD].

Be brutally honest:
1. Should I pivot? (Yes/No with reasoning)
2. If yes, what should I pivot TO?
3. What signals am I ignoring?
4. What would a YC partner say about this business?
5. The one metric I should obsess over right now
```
